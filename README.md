# AWANIL STORE — React + Supabase E-Commerce Platform

AWANIL STORE is a full-featured e-commerce demonstration application built using React, Vite, Bootstrap 5, and Supabase PostgreSQL backend with Row Level Security (RLS).

---

## 🌟 Key Features

- **Backend Integration**: Real-time Supabase connection for product management, authentications, user profiles, and contact messaging.
- **Security**: PostgreSQL Row Level Security (RLS) ensures only users with the `admin` role can mutate database records.
- **E-Commerce Flow**: Dynamic product grid, category filter, product search, cart persistence with `localStorage`, and external checkout redirects to Flipkart.
- **Light/Dark Mode**: Persisted theme context applied seamlessly across components.
- **Admin Panel**: Dashboard analytics, product list, add product, edit product, and delete product functionality.
